{{ sample }}
  • Use valid JSON: comments and trailing commas are not supported.
  • Title: 1-200 characters; PBI/Task number: up to 100; URL: up to 2,048 and must start with http:// or https://.
  • Status: open, in_progress or closed. Estimate: a finite number or null.
  • Maximum 20 nesting levels, 500 issues and 2 MB per import, and 5,000 issues per room (including children). Split larger boards into several imports.
  • Imports add new issues. IDs, timestamps, parentId and unknown fields are ignored. Reimporting creates duplicates.
  • Only one active branch is supported. The last in_progress issue and its ancestors remain active; other active branches become open. The preview shows this normalization. Importing an active branch also reopens other active branches on the board.
  • Preview edits update the JSON and the import. Nothing is saved until you press Import issues.
