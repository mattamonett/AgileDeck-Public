# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion about the work. Harassment, personal attacks, discriminatory language and sharing someone's private information are not acceptable in issues, pull requests or any other project space.

To report a problem, use GitHub's private vulnerability reporting on this repository's **Security** tab (it reaches the maintainer privately), or contact the maintainer through their GitHub profile. Reports are handled confidentially. The maintainer may remove content and block people who break these rules.
